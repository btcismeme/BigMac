## Key Lessons From Memory Cycle Trading

### What Typically Goes Wrong

1. **Timing the Inflection Too Early**: Trying to catch cycle bottom is sucker's game. The $65 level (Jan 2026) felt like "obvious bottom" but crashed another 5-10% before recovering. **Lesson**: Wait for supply chain confirmation (not financial models) before deploying heavy capital.

2. **Anchoring on "Fair Value" vs. "Cycle Value"**: Selling into rallies because "stock is 20% above DCF fair value." Meaningless during cycle inflections — valuation expands 2-3x during upcycle. **Lesson**: Use cycle stage (via inventory reports, spot pricing curves), not discounted cash flow.

3. **Underestimating Structural Demand Shift**: Many analysts treated "AI demand for memory" as temporary NVDA tailwind. Actually represents 5-10 year structural shift in data center architecture (CXL memory adoption, HBM ubiquity). **Lesson**: Separate temporary event demand from structural TAM expansion.

4. **Binary Earnings Bet vs. Cycle Positioning**: Temptation to go all-in on earnings outcome (bull call spreads, straddles). Better to use earnings as **confirmation point** in multi-quarter thesis. **Lesson**: Earnings are a waypoint, not the destination.

## What Could Go Wrong (Downside Risks)

1. **Macro recession signaling** (June 2026 economic data): If June jobs report or PMI comes in weak, entire semiconductor complex sells off 5-10% regardless of MU fundamentals.

2. **AI capex slowdown narrative shift**: If cloud providers (Meta, Microsoft, Google) guide down AI infrastructure spending, DRAM demand thesis collapses 12-18 months forward. Real risk but low probability in Q2 2026.

3. **Gross margin disappointment**: If MU guides gross margins lower (due to CXL ramp-up costs, NAND pricing stickiness), institutional rotation pivots from "growth stock" to "cyclical." Stock could rally on earnings but then fade.

4. **Earnings blowout + "priced in" fade**: Street has raised expectations significantly. If MU beats by only 2%, that's "priced in" and stock fades 3-5% post-earnings despite good numbers.

## Reusable Framework: Memory Cycle Inflection Plays

### Step-by-Step Process

**Phase 1: Identify Cycle Bottom** (4-8 weeks before inflection signal)
- Monitor spot pricing curves for memory (DRAM, NAND)
- Track OEM inventory reports (Gartner, IDC)
- Look for industry guidance "plateau" (stops going down)
- **Entry point**: When industry cuts guidance → stops cutting (inflection floor)

**Phase 2: Confirmation via Supply Chain** (2-4 weeks into recovery)
- Channel checks: talk to customers or use industry surveys
- Bit shipment forecasts: Gartner raises bit growth forecast QoQ
- Spot pricing: Memory pricing starts rising (even small +0.5% QoQ is signal)
- **Entry point**: After supply chain confirms before financial guidance catches up (2-3 week window)

**Phase 3: Structure Selection**
- **Conservative** (0-6 weeks to inflection): Bull call spreads, long equity + call hedge
- **Aggressive** (2-4 weeks pre-inflection): Long calls, call diagonals, naked long (if high conviction)
- **Balanced** (ongoing thesis): Equity core + tactical option leverage

**Phase 4: Inflection Confirmation** (earnings or analyst day)
- Earnings beat + guidance raise = 8-12% 2-day move
- Earnings beat + flat guidance = 2-4% move (priced in)
- Earnings miss but guide up = 1-3% move (thesis still valid but delayed)

**Phase 5: Cycle Positioning** (post-inflection, 12-24 months)
- Don't exit on first pop; memory cycle rallies last 12-18 months
- Hedge with puts only if macro recession signals emerge
- Take partial profits at +15-20% if risk/reward deteriorates
- Hold core for cycle full upcycle (typically 300-400% total move from trough to peak)

The generated PNG includes the following sections:

1. **交易概览** (Trade Overview)
